# brahamastra

This repository hosts a minimalist fullscreen clock website.

## Folder structure
- `ipad/stand-by-clock/` – contains the web app files (`index.html`, `style.css`, `script.js`).
- Additional device folders (e.g., `iphone/…`) can be added following the same pattern.

## GitHub Pages deployment
The site is published using **GitHub Pages**. After enabling Pages for the repository (Settings → Pages → Source: `main` branch), the live site is available at:

```
https://shrajan8071.github.io/brahamastra/ipad/stand-by-clock/
```

Visiting the URL shows the ambient clock as designed.

Feel free to add more device‑specific folders or customize the clock further.
